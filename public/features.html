Features

Tools for a transparent TikTok publishing workflow

Relampago de Ofertas helps authorized users prepare, review, confirm and monitor video publication.

Authorized TikTok connection

The application uses TikTok authorization so users can connect accounts they own or are authorized to manage.

Video selection

Users choose the video that will be sent and can review the selected file before submission.

Caption review

Users can review or edit captions and related publication information before confirming the request.

Explicit publication confirmation

No publication request is sent until the user confirms the final content and selected account.

Publication status

The application displays the processing state and response received from TikTok.

Connection management

Users can disconnect their TikTok account and revoke the application’s access.

User responsibility

Users remain responsible for their content

Users must have the necessary rights to publish videos, sounds, images, captions and other materials submitted through the application.
