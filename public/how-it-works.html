How it works

From account authorization to publication status

The complete flow is designed to keep the user informed and in control.

1

Connect TikTok

The user starts the official TikTok authorization flow and grants only the permissions required by the application.

2

Select a video

The user chooses the video content that should be prepared for publication.

3

Review publication details

The application displays the selected content, destination account, caption and related settings.

4

Confirm the publication

The publication request is sent only after the user explicitly confirms the action.

5

Monitor the result

The application presents the processing state or publication result returned by TikTok.

6

Disconnect when needed

The user may revoke access through TikTok account settings and stop future publication requests.

Important

Relampago de Ofertas does not request or store the user’s TikTok password. Previously published content may remain on TikTok after the application is disconnected.
